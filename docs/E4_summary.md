# E4：機制推導的修法（雜訊白化）——正式結論

對應研究計畫 §6「E4：機制推導的修法」，日期 2026-09-07。在全部 60 支影片規模上
完成（病理曲線用全資料集 6000 張影格；兩條合成指紋曲線沿用 E0.5/E3 已校準的
500 張 pilot 底圖）。

## 背景：E3 留下的殘餘地板

E3（見 `docs/E3_summary.md`）證實 color jitter 能把 color_shift（高階/色彩類
指紋）壓到接近 chance，但 pattern_noise（低階/感測器雜訊類指紋）幾乎不受影響，
維持在遠高於 chance 的殘餘地板——機制上，color jitter 是色彩空間的仿射變換，
數學上動不到無色高頻雜訊的空間結構。E4 要測的是：一個**直接針對雜訊本身設計**
的手段，能不能把這條壓不下去的曲線也壓下去。

## E4a：雜訊重合成 / 白化的設計

對每張圖：先用小幅高斯模糊估計低頻部分，取原圖與模糊版的差當作高頻殘差；再把
這個殘差按強度比例（`whitening_strength ∈ [0, 1]`）替換成**每張圖各自獨立抽樣**
的新雜訊。強度 0 時完全還原原圖（模糊+殘差重組是恆等操作，已驗證位元組級一致）；
強度 1 時殘差完全替換成獨立雜訊。

這直接命中 pattern_noise 之所以可被 probe 讀出來的關鍵性質：**同一個
synthetic_class 的每一張圖都疊了同一張固定的雜訊紋理**（模擬真實感測器 PRNU
「同一台相機、每張影格都留下相似雜訊指紋」的性質）。白化把這個「固定、可重複」
的雜訊換成「每張圖各自獨立」的雜訊，讓 probe 沒有固定指紋可以認。

實驗設計：jitter 固定在 E3 的標準強度（等同 E0.5/E1 用的 COLOR_JITTER），額外
疊加白化強度 sweep——測的是「在既有 augmentation 之上加上這個新手段」，不是
重新測 jitter 本身。

## 結果

| whitening_strength | pattern_noise | color_shift | polyp_label | SSIM |
|---:|---:|---:|---:|---:|
| 0.00 | 43.0% | 23.5% | 88.6% | 0.917 |
| 0.25 | 41.2% | 24.2% | 88.4% | 0.912 |
| 0.50 | 30.7% | 25.3% | 88.3% | 0.888 |
| 0.75 | 26.5% | 25.5% | 88.1% | 0.847 |
| 1.00 | **24.1%** | 26.2% | **87.7%** | 0.792 |

（chance = 25%，polyp majority baseline = 85.8%。whitening_strength=0 這一點
跟 `results/e3_dose_response_report.md` 的 jitter-only 基準——pattern_noise
43.0%、color_shift 23.5%、polyp_label 88.6%——完全一致，互相校驗。）

## 解讀：驗證迴路成立

- **pattern_noise 單調下降到 chance 以下**（43.0% → 24.1%，chance 25%）——
  E3 裡壓不下去的曲線，這次確實被壓下去了。機制推導的修法（打亂雜訊的空間結構、
  換成每張圖獨立的隨機雜訊）有效：原本殘留的感測器雜訊類指紋不是「什麼手段都
  碰不到」，只是「color jitter 這類色彩空間變換碰不到」，換一個直接作用在雜訊
  頻域/空間結構上的手段，就能把它壓下去。
- **color_shift 維持平穩**（23.5% → 26.2%，變化在標準差範圍內）——符合預期：
  白化動的是高頻雜訊殘差，不是色彩統計量，兩者互不干擾，證明這個修法是
  **針對性**的，不是「隨便加點雜訊全部都會受影響」的巧合。
- **polyp_label 幾乎零代價**（88.6% → 87.7%，只掉 0.9 個百分點，全程遠高於
  majority baseline 85.8%）——在把 pattern_noise 壓到 chance 以下的同時，真實
  病理訊號幾乎沒有付出代價。
- **SSIM 隨強度下降但仍在合理範圍**（0.917 → 0.792）——白化比單純 color
  jitter（E3 最高強度 SSIM 0.883）更容易改變影像外觀，符合預期（直接操作高頻
  殘差比色彩空間仿射變換更「有感」），但沒有到「trivial destruction」的程度
  （對照組：對 clean 底圖套用同樣白化，SSIM 最低點仍有 0.792，見
  `results/e4_ssim_control.csv`）。

**這是計畫 §6 E4 定義的最好結果**：驗證迴路完全成立——加上機制推導出來的修法後，
原本平的那條曲線真的開始下降，且是在幾乎不犧牲診斷訊號的前提下做到的。這代表
「augmentation 消除捷徑的機制是讓特徵在 crop 間不可預測，但只能作用在有參數化
的維度上」這個核心假說得到了雙重驗證：E3 證明 color jitter 碰不到雜訊類指紋，
E4 證明**換一個對準雜訊維度設計的手段就碰得到**——不是雜訊類指紋本質上無法
被消除，只是需要對症下藥。

## 已知限制

1. 白化強度 1.0 時的 SSIM（0.792）已經明顯低於 E3 全程維持的 0.88+，代表這個
   實作方式（完全替換高頻殘差）對影像外觀的影響比色彩類 augmentation 更大；
   雖然病理 probe accuracy 幾乎沒掉，但沒有對更細緻的下游任務（例如小病灶的
   邊緣偵測）做直接測試，不能排除某些對高頻細節更敏感的任務會受影響。
2. blur_sigma 固定在 1.0 像素，沒有做敏感度分析——這個超參數決定「多細的頻段
   算雜訊、多粗的頻段算內容」，選得不對可能低估或高估白化對病理訊號的代價。
3. 白化的「新雜訊」振幅是從每張圖自己的殘差標準差估計出來的（不是額外的超
   參數），這個設計選擇讓白化強度=1 時新雜訊的振幅自動貼合原本殘差的振幅，
   但也代表如果原圖殘差振幅本身跟感測器雜訊振幅不同調，白化的「等效強度」
   可能因影格而異。
4. 跟 E3 一樣，兩條合成指紋曲線用 pilot 規模（500 張、5 支影片）的底圖，真實
   polyp_label 曲線才是全資料集規模——這個範圍劃分的理由同 E3。
